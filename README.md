# ADC LAB · 走 A 综合训练场

使用 TypeScript、Phaser 3.90、Vite 和 Canvas 的桌面浏览器 ADC 训练模拟器。

**当前版本：0.4.0，第四阶段「屏外技能躲避」已实现。** 已有兵线补刀、走 A、八方向直线技能和生命/躲避统计；完整设置面板留待第五阶段。

## 安装与运行

需要 Node.js 22.12+ 或 24 LTS、npm。首次安装依赖需要网络。

```sh
npm install
npm run dev
```

打开终端输出的本地地址，默认 http://127.0.0.1:5173/ 。Windows PowerShell 如限制 npm.ps1，可使用 `npm.cmd install` 和 `npm.cmd run dev`，无需修改执行策略。

```sh
npm run typecheck  # TypeScript 检查
npm test           # 移动、输入、平 A、兵线、技能与躲避回归测试
npm run build      # 检查并构建 dist/
npm run preview    # HTTP 预览构建产物，默认 4173 端口
```

构建结果需要通过 HTTP 服务打开，不能直接双击 dist/index.html。

## 操作

| 操作 | 效果 |
| --- | --- |
| 地面右键点击 / 按住右键 | 移动 / 持续更新目的地；松开后到达最后目的地再停止 |
| 左键红方小兵的模型、血条或名称 | 单击即持续平 A；超距自动靠近；右键可中断 |
| A → 左键敌人 | 显示射程后指定目标攻击 |
| A → 左键地面 | 优先选择鼠标附近敌人；否则沿途寻敌，击杀后继续原路线 |
| ESC / 右键 | 取消 A 指令待命并隐藏范围圈 |
| 前摇中右键 | 取消未完成的攻击，没有弹道或伤害 |
| 发射后右键 | 可移动取消后摇，已发射弹道继续飞行，冷却不被跳过 |
| S | 立即停止移动、追击与自动攻击，取消 A 待命并回到站姿；已发射弹道继续飞行，冷却保留 |
| G | 切换距离网格 |
| F11 | 浏览器全屏 |

无需按 A 也能直接左键攻击。按住右键时再按左键，仍能切换到指定目标普攻。悬停会高亮目标；点选优先级是模型、血条、名称，避免名称遮住其他单位。蓝方小兵不可被玩家攻击。普通左键空地不会自动攻击。

只有 A 待命时显示攻击范围圈。确认、ESC、右键或失焦均退出待命；范围圈半径为配置射程加玩家碰撞半径，攻击距离按两单位碰撞圆的边缘间距判断。

A 待命时，鼠标悬停存活红方小兵的模型、血条或名称会切换为原创红色环形攻击准星，热点位于圆心；悬停空地、友军或死亡单位时使用小手套。确认攻击、ESC、右键、移出地图或失焦会恢复原指针。准星固定为 32×32 屏幕像素，不随地图缩放改变尺寸。

## 生成开关

右侧面板的「兵线生成」和「场外技能」为两个独立开关，默认均开启，可任意组合：

- 关闭兵线：停止新波次，现有蓝红小兵立即生命归零并移除，同时清理小兵攻击和玩家指向它们的弹道、追击。地面移动继续。主动清场不增加 CS、漏刀或总死亡。
- 重新开启兵线：保留训练时间、成绩和波次进度，等待 0.5 秒生成下一波，不补发关闭期间的波次。
- 关闭场外技能：立即清除当前技能弹道和命中反馈，并停止新发射，不增加有效躲避；兵线继续正常运行。
- 重新开启场外技能：按当前难度的首次延迟恢复生成，保留生命值及已有统计。

S 会撤销持续右键输入，保持按住右键也不会恢复旧移动指令，需重新点击下达指令。停止可以取消未完成的前摇；发射后的冷却独立计时，反复按 S 不能突破攻速上限。

## 玩家像素模型

玩家使用已制作的绿色蝴蝶结持炮角色：静止站立、五帧跑步循环、攻击前摇举炮。跑步顺序为 `1 → 4 → 2 → 5 → 3 → 5 → 2 → 4`，满速每步 70ms，并随实际移动速度减慢。停止、前摇取消和后摇移动会立即切换对应姿势；攻速、前摇时长及伤害仍由原状态机决定。

素材采用像素采样，统一脚底位置和可见高度。角色保持直立，按原移动模型的朝向左右翻转；仅有单侧素材，不显示八方向立绘。配置位于 `src/config/playerVisuals.ts`，原图和处理提示词位于 `public/assets/character/`。

## 兵线与统计

蓝红双方小兵按用户两张参考简化成粗色块像素素材：近战保留黑脸白眼、灰色兜帽边、大菱形盾与钝器；远程保留浅色镶边兜帽长袍与施法姿势。省略盾牌花纹、金属纹理和复杂衣褶，衣料与施法焦点按红蓝阵营配色。素材位于 `public/assets/minions/`，显示尺寸、脚底锚点位于 `src/config/minionVisuals.ts`。两类小兵保持直立、按移动/攻击朝向左右翻转，附带轻微行军起伏和前摇倾身；血条优先级与原有点选布局沿用。炮车暂时沿用程序绘制模型。

- 开始后 0.5 秒刷新第一波，之后每 30 秒同时刷新蓝、红双方。
- 每方每波 3 个近战兵、3 个远程兵；第 3 波开始，每 3 波各加一只炮车。**第一次炮车在训练时间 01:00.5 左右出现。**
- 小兵从斜路两端出发，按纵向单列行军：3 近战在前、3 远程在后，间隔 48 世界单位；炮车波再在队尾加炮车。双方在固定世界坐标的中央附近交战，接敌后近战展开靠近挥击，远程留在后方发射弹道。玩家初始站在交汇点侧后方；无人操作时两队也会独立交战和继续推进。
- **道路是底层导航约束。** 地图绘制与小兵共用 `src/config/road.ts` 的中心线、倾斜角度和路宽；小兵出生点、出口、行军、追击、近战展开、转向弧线和互相让位都限制在石板路面内。边界按小兵半径和 8 单位余量向内收缩，整个身体不能跨到草地上；道路与世界外框共同限制目标点。
- 若将小兵强制带到路外，会取消未完成的攻击、清空追击目标，优先按自身移速与转向走回路面内侧，再恢复寻敌和推进。不会瞬移回路面，也不会追着路外敌人离开道路；回路过程中暂不参与单位分离，避免再次被挤走。这个规则只限制小兵，玩家仍能自由移动并穿过兵线。
- 近战攻击在前摇完成时近距离结算；远程与炮车使用飞行弹道。发射者死亡不会撤回已发出的弹道，目标死亡则丢弃追随它的旧弹道。
- 各类型拥有独立血量、攻击力、攻击间隔、前摇、射程、速度、护甲和半径，并按配置的 90 秒周期成长。死兵不会原地复活，下一波是新单位。
- 活着的小兵始终显示血条。红方血条变金色表示当前血量不高于玩家一发普攻的理论伤害；其他小兵和弹道仍可能抢先击杀它。
- 小兵血条在独立的世界显示层，优先于单位模型、玩家、技能、弹道、伤害数字与单位名称，密集交战时也不会被这些对象盖住；死亡淡出和对象销毁会同时清理血条。
- 玩家普攻打出红方小兵的**最后一击**才计 CS；玩家仅削血而由蓝方兵收尾计漏刀。蓝方死亡只加入「总死亡」，不影响补刀成功率。
- 成功率为 `CS / (CS + 漏刀)`；总死亡同时包含蓝、红双方。死亡只结算一次，重复命中尸体不会增加统计。
- 本版没有塔：幸存小兵抵达对方出口区域后离场。离场不属于死亡，不计 CS、漏刀或总死亡。单个死兵的淡出清理也不再次计数。
- 为专注补刀，本阶段小兵只寻找敌方小兵，玩家不进入小兵仇恨。玩家与双方小兵之间没有移动碰撞：可以直接穿过或重叠，不会阻挡或推走小兵。小兵之间仍使用软分离维持交战站位；攻击距离、弹道命中和地图边界仍使用各自半径。没有复杂地图寻路障碍。
- 右侧显示 CS、漏刀、成功率、总死亡、波次、下一波倒计时、双方存活数和模拟训练时间。发射/命中数是普攻调试计数，不等于 CS。刷新页面重新开始；完整数据重置留待设置阶段。

## 屏外技能与躲避训练

- 右侧「技能难度」可选**简单 / 进阶**，默认简单。简单在开始 2 秒后发射首发，之后约 3 秒一发；进阶约 0.5 秒一发，来袭频率约为简单的 **6 倍**。两档均带 ±35% 间隔随机变化；弹道类型、八方向与瞄准方式独立随机。
- 训练中可随时切换难度：按新的频率调整下一发冷却，现有弹道继续飞行，生命、CS 与躲避统计保留，不因切换补发旧技能。重复选择同一档不会重置冷却。难度只影响技能频率与同时在场上限（简单 12、进阶 24），弹速、伤害和小兵攻速保持各自独立配置。
- 发射点以玩家为参照，越过**当前游戏画布可见世界矩形**的北、东北、东、东南、南、西南、西、西北边界，再增加安全间距。头部和尾迹都在屏幕外；没有在画面内凭空创建弹道。窗口大小和相机投影改变后会重新计算后续发射点。
- 瞄准方式为当前位置（30%）、基于当前速度的有限时间拦截预测（40%）、玩家附近随机偏移（30%）。只有发射时瞄准一次，发射后方向和速度固定，不追踪角色。
- 来袭技能属于红方：可伤害玩家和蓝方兵，红方兵不挡弹。玩家与小兵之间仍然没有移动推挤。

| 训练弹道 | 外观 | 速度 | 完整判定宽度 | 基础伤害 | 命中行为 |
| --- | --- | ---: | ---: | ---: | --- |
| 穿透 | 紫色 | 620 | 34 | 110 | 穿过多个单位，每个单位至多受一次伤害 |
| 长矛 | 红焰长矛 | 540 | 18 | 70 | 首个有效目标后消失；按实际飞行距离线性增伤，1600 距离达到上限 2.2 倍 |
| 能量 | 蓝色冰能弹 | 700 | 24 | 90 | 首个有效目标后消失 |

这些全部是可校准的原创训练参数，位于 `src/config/skillshots.ts`，不声称还原任何英雄的官方技能数值。弹头按宽度形成圆形截面，使用两个运动圆的相对连续扫掠检测；尾迹仅是视觉效果。同一时间步内按真实接触先后结算，飞行弹道不会跳过挡在前面的小兵。

玩家生命为 1000，受伤后有 0.65 秒保护与闪烁反馈，重复触碰保护中的玩家只记录「保护免伤」，不扣血。生命归零后保持原位置、移动操作与全部统计，2 秒后自动回满，再保护 1.2 秒，方便连续训练。头顶与右侧都有生命条；受击有环形闪光和伤害数字。

**有效躲避的口径：** 弹头首次进入可见区域时，计算玩家维持当时速度继续前进（到达地图边缘后停下）是否会与弹道相交；计算范围限于该弹道剩余寿命、距离和当前视窗内的未来飞行段。只有这种反事实会命中的弹道才标记为威胁。随后实际没有触碰玩家、没有被小兵阻挡、且弹道正常结束，才计一次有效躲避；结算会稍晚于擦身而过。已真实造成伤害的弹道也标记为威胁。

本来就打偏或保持原速度就不会命中的弹道自然飞出，不计躲避；被蓝兵挡住单独记录；无敌帧接触不计躲避；主动关闭/清理弹道也不结算躲避。该统计刻意保守，不奖励技能入屏前已经完成的避让，不是每发未命中都计分。右侧的「技能命中」统计实际造成伤害的次数，与保护免伤分开。

`DODGE_CONFIG` 独立控制速度、宽度、伤害、首次延迟、间隔、抖动、预测/偏移概率、寿命与单位上限；`DODGE_DIFFICULTIES` 定义两档频率和容量倍率；`VITALS_CONFIG` 控制血量、受击保护和恢复。右侧两个生成开关分别调用兵线与技能的独立清理接口；暂停和重置继续按第五阶段开发。本版默认兵线与技能都开启，刷新页面重新开始并恢复简单难度。

## 小兵参数与参考来源

兵线参数集中于 **src/config/minions.ts**，核对过的基础记录位于 **src/config/minionReference.ts**，玩家和普攻参数位于 **src/config/game.ts**。这些是可校准训练参数，**不声称与任一官方版本整局实战完全一致**。

| 类型 | 基础血量 | 基础攻击力 | 训练攻速（次/秒） | 训练攻击间隔（秒） | 边缘射程 | 速度 | 护甲 | 半径 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 近战 | 430 | 11 | 0.625 | 1.60 | 28 | 55.5 | 0 | 16 |
| 远程 | 275 | 19.5 | 0.3335 | ≈2.999 | 225 | 55.5 | 0 | 14 |
| 炮车 | 750 | 36 | 0.50 | 2.00 | 260 | 52.5 | 5 | 21 |

2026-10-17 核对 CommunityDragon 的 **16.20 / 26.20 客户端 `CharacterRecords/Root`**：
[近战记录](https://raw.communitydragon.org/16.20/game/data/characters/sru_orderminionmelee/sru_orderminionmelee.bin.json)、[远程记录](https://raw.communitydragon.org/16.20/game/data/characters/sru_orderminionranged/sru_orderminionranged.bin.json)、[炮车记录](https://raw.communitydragon.org/16.20/game/data/characters/sru_orderminionsiege/sru_orderminionsiege.bin.json)。这三类的基础血量、攻击力、攻速和攻击施法/动画时长取自这些记录。CommunityDragon 是第三方客户端数据提取，并非 Riot 官方 API；记录包含多种模式，本项目使用 Root，未取 URF 等模式的数据。

当前按用户反馈将小兵攻速降到参考基础值的 **50%**，配置为 `MINION_ATTACK_SPEED_SCALE = 0.5`；原始参考攻速仍分别为近战 1.25、远程 0.667、炮车 1.0 次/秒。`attackInterval = 1 / (referenceAttackSpeed * scale)`，避免把“每秒攻击次数”当成“每次等待秒数”。前摇比例分别用客户端约 `0.393/0.8`、`0.47/1.5`、`0.3/1.0`，前摇与攻击间隔一起按训练倍率放慢，冷却仍独立于取消后摇。120 Hz 下实际出手会有至多一个时间步的量化延迟。

基础血量不等于实战某波出生后的最终血量：客户端地图脚本、出生时修正和版本成长可能额外改变它们。训练第一波从上表基础值开始，之后使用独立成长配置，不模拟出生前的完整召唤师峡谷时间轴；射程、移速、护甲、半径与成长仍是可校准训练值。

玩家移速 195，为调整前 325 的 60%；近战/远程兵 55.5、炮车 52.5，分别为调整前移速的 30%。这里只调整行军速度，攻速、前摇和弹道速度保持独立配置。

默认采用早期兵线练习结构。Riot 的 [26.1 版本说明](https://www.leagueoflegends.com/en-us/news/game-updates/patch-26-1-notes/) 记录了首炮车波改为第 3 波，以及 14/30 分钟后的 25/20 秒刷兵变化。本版固定 30 秒节奏，不模拟这些中后期波次变化，且第一波提前到 0.5 秒方便练习。

[26.9 版本说明](https://www.leagueoflegends.com/en-gb/news/game-updates/league-of-legends-patch-26-9-notes/) 提供了近战兵 430 基础血量、每 90 秒 35 血量成长，以及小兵互相攻击的当前血量附加伤害比例参考。本版为近战/远程/炮车配置 2%/3.5%/5% 目标当前血量的附加伤害，仅作用于小兵互相攻击。其他成长、碰撞和 AI 仍是本训练场的校准实现；为适配紧凑地图，射程和速度尤其做了调整。没有金钱、经验、塔伤害、装备或英雄仇恨系统。

`waveInterval`、`meleePerWave`、`rangedPerWave`、`firstCannonWave`、`cannonEveryWaves` 控制波次；`growthInterval` 和各类型 `healthGrowth/damageGrowth` 控制成长。`maxActiveMinions` 为长时间运行保护上限，超过上限会跳过该波并显示提示。

`queueSpacing` 控制纵向队列间隔，`meleeFormationSpacing/meleeApproachDistance` 控制接敌后的近战展开站位；`frontSpawnDistance` 为领头兵距中心的距离（500），`routeEndDistance` 为对侧出口距离（820）。世界与道路延长约 40%，但仍在固定单屏中完整显示。

道路默认半宽 188，`ROAD_CONFIG.edgeInset` 为边缘余量，`returnInset` 为回路时向道路内侧多走的距离。`LaneConfig.roadHalfWidth/roadEdgeInset/roadReturnInset` 默认引用同一份道路配置，便于独立模拟测试；实际场景修改路宽应调整共用的 `ROAD_CONFIG`，避免视觉与导航边界分离。

玩家普攻独立配置为 0.9 次/秒、前摇比例 28%、弹速 1150、射程 300、攻击力 60。`attackMoveRule` 默认沿途选玩家附近最近敌人，可设为 `move-only`；鼠标附近优先选敌的半径与沿途搜索半径也分别可配置。

## 技术架构


- 强制 Phaser Canvas 渲染，不依赖外部美术、字体或音效请求。
- 世界大小为 1540×1100，固定镜头等比完整显示地图。游戏画面在可用区域中居中，右上角按钮可收起、展开数据栏；收起后画面在整个窗口中居中，训练和统计继续运行。左上角小字显示帧率和实时移速（静止时为 0）。窄屏时数据栏移到画面下方，切换按钮位于右下角。鼠标保持 24×26 小手套，热点 (4,3) 位于食指尖。
- 所有实际移动、攻击、弹道与碰撞都按 delta time 推进。兵线、玩家与技能共用累加器统一为 1/120 秒时间步，30/60/120/144 FPS 下得到相同结果。画面失焦或卡顿后单帧最多推进 0.1 秒，避免跨屏跳跃；训练时间是模拟时间，后台标签页会变慢。
- 普攻冷却独立于后摇动画，右键不能重置下一次允许攻击的时间。前摇被取消不产生发射事件；反复点击同一目标不重置前摇。
- 死亡、尸体清理与出口离场是三条不同流程；单位 ID 包含阵营、波次、类型和序号，旧弹道不会命中下一波新单位。
- 静止训练靶模型保留供第二阶段回归测试使用，实际游戏已替换为动态兵线。

## 验证与阶段

`npm test` 覆盖移动边界和转向、多键输入、直接左键点选、前后摇取消、攻速上限、追击、友方保护、无移动推挤、兵线和补刀，以及八方向/不同视窗下的屏外生成、固定轨迹、三类技能、预测、移动圆连续碰撞、首个接触、穿透去重、长矛距离伤害、自然飞出与真实威胁、挡弹、无敌帧、恢复、主动清理、对象回收和不同帧率一致性。

手动验收：等待两队在中央交战；点击红兵模型/血条/名称攻击；在金色低血量提示时尝试补刀；观察 CS 与漏刀；按 A 看范围、ESC 取消；发射后穿插右键移动；等待下一波和第 3 波炮车；调整窗口确认地图、点选与面板对应正确。

屏外技能验收：保持窗口在前台，观察三种像素弹道从画布边缘进入，透明背景且弹头朝向飞行方向；静止等待命中查看血量与次数；入屏后横向右键避让查看有效躲避；站到蓝兵后方观察红焰长矛/蓝色能量弹挡弹，紫色箭矢仍会穿过；生命归零后验证原地恢复；按 A 悬停红兵确认攻击准星仍正常。小窗口右侧面板可滚动。

## 美术与边界

场景、炮车、金色手套和命中反馈由代码绘制；蓝红近战与远程小兵根据用户指定参考图，经内置 imagegen 制作像素版本，位于 `public/assets/minions/`。玩家像素角色根据用户参考图制作，含站立、五帧跑步与前摇，保存于 `public/assets/character/`。三种屏外弹道使用用户提供的图片，经内置 imagegen 去背景及朝向整理后保存于 `public/assets/skillshots/`，按单张素材移动和旋转。原图文件未修改，素材与完整处理提示词见对应目录 README。没有音效、塔、野怪、英雄技能、装备或联网功能。本项目为独立训练原型，与 Riot Games 无关联。
