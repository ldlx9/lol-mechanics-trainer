Image 2 is the compact passing-step frame. Produce the NEXT running step after image 2, with the OPPOSITE extended stride compared with image 1. No redesign, no added details, same simple broad pixel clusters, same palette and square canvas framing. ONLY animate below the green skirt and a very slight skirt swing. Leg silhouette instructions are critical: in image 1 the LEFT-side boot is raised high behind and the RIGHT-side boot stretches downward. In this NEW frame reverse those vertical positions: the LEFT-side boot should extend DOWN-LEFT and be the LOW foot at the existing ground baseline; the RIGHT-side boot should be lifted UP-RIGHT with a visibly bent knee, about two logical pixels above the ground. Two legs must attach naturally to the same hips, with readable alternating stride. This should transition smoothly through image 2 on either side, for the loop image1 -> image2 -> NEW -> image2. Do not repeat image1's left-high/right-low foot pose. Keep the body center, weapon and head stationary and match the existing feet baseline, sprite size, camera angle and right-facing direction. Output ONLY one whole character, one frame, same square dimensions and true alpha transparency. No text, background, ground, shadow, effects, projectile or sprite sheet. Do not horizontally mirror the entire sprite.
